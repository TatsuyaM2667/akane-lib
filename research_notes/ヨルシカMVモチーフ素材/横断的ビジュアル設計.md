> 情報の格付け: **一次**（制作会社インタビュー・公式ポートフォリオ・技術誌）と **二次**（ファン考察・デザイン解説記事）を明示する。UI 用の HEX 値はすべて**筆者の提案値**であり、MV の実際のカラースクリプトから引用した数値ではない。

### 1.2 UI 翻訳時の要点（抽出）

- **「1つの空間としての統合」が最も重要な原則**。背景・文字・装飾を別レイヤーにせず、同じ輪郭・同じグレイン・同じ光源方向で包む。CSS では `isolation: isolate` + 共通トークンのグレイン/ビネットで再現できる。
- **質感は「画像」ではなく「処理」として定義する**。新版画・リソグラフ・フィルム・紙はすべて、ノイズ／ブレンド／わずかなズレ／トーン制限の組み合わせとして捉え直せる（後述§3）。
- **色は「 era の固定」ではなく「場面の遷移」**。『千鳥』の青→橙→紺、『櫂』の淡い紫/青→橙/深紅→紺→クリームなど、1 本の中で温度が変化する（二次情報）。UI ではテーマトークンを「ムード」単位で切り替える設計が合致する。

## 4. アクセシビリティ注意点

### 4.1 コントラスト（最もリスクが高い）

- WCAG 1.4.3 は通常テキスト **4.5:1**、大テキスト **3:1**。**端数切り上げ不可**（4.49:1 は不合格）。グラデーション・半透明・画像上のテキストも対象で、WCAG 自身は測定方法を規定しないため**最もコントラストの低い点**で評価する（F83）[出典](https://webaim.org/articles/contrast/); [出典](https://accessibility.build/guides/text-over-images)。
- 白文字をどんな背景にも通す黒スクリムの「天井」は **3:1 で 42%、4.5:1 で 54%、7:1 で 66%**。実務では 55% に少しマージンを取る例が紹介されている。オフホワイト文字・色付きスクリムは再計測が必要 [出典](https://accessibility.build/guides/text-over-images); [出典](https://ishadeed.com/article/handling-text-over-image-css/)。
- `mix-blend-mode` は意図しない色でコントラストを下げる。リソ風 CSS ライブラリは「コントラスト・フロア」ガードを追加して本文を AA 未満に落とさないようにしている。**本文にはブレンドをかけず、装飾レイヤーにのみ適用**する [出典](https://osmanyy.com/projects/risograph-css/); [出典](https://chrislemke.github.io/website_designs/designs/Risograph.html)。
- アイコン・コントロール境界は 1.4.11 で隣接色に対して **3:1**。画像/グラデ上でも最悪点で確認 [出典](https://accessibility.build/guides/text-over-images)。
- 自動で切り替わるカルーセルは 5 秒超で一時停止手段が必要（2.2.2）。MV 的なムービー背景にも、5 秒超の動きには停止操作を設ける [出典](https://accessibility.build/guides/text-over-images)。

### 4.2 モーション（prefers-reduced-motion）

- 基本は**静止状態をデフォルト**とし、アニメーションは `@media (prefers-reduced-motion: no-preference)` 内で有効化する方式が推奨。パラメータを緩める場合のみ `reduce` 内で上書き。`animation-duration: 0.01ms` の全局適用は逆に酔いやすいので禁止。色・背景色の非空間トランジションは残してよい [出典](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/motion)。
- グレインを動かす場合、実写のフィルム映写は **8–12fps** で十分「フィルム」に見えるが、粗いノイズは光感受性リスク。WCAG 2.3.1 は約 341×256px 領域で 10% 以上の輝度変化を 1 秒 3 回までに制限。`baseFrequency=0.02` では 1 フレームで閾値超過し得るが `0.08` では約 0.013 に留まる例が報告されている。粗い設定では 3fps 以下に制限する [出典](https://sunsided.github.io/web-visual-fx/noise)。
- 回転するリール (#18)、流れる車窓 (#6)、多重露光の平移 (#17) は **`transform` と `opacity` のみ**。レイアウトを伴う `top/left/width` のアニメは CLS・INP を悪化させる [出典](https://web.dev/articles/animations-guide); [出典](https://shopify.dev/docs/storefronts/themes/best-practices/performance/use-transform-for-animations)。

### 4.3 パフォーマンス

- `feTurbulence` はピクセル単位の生成で、要素が再描画されるたびに再計算される。フルスクリーンの live filter は低端末で数 fps に落ちる可能性。**`stitchTiles="stitch"` で小さなタイルを一度だけ生成し、繰り返し表示**する方式を採る [出典](https://craft.gustavofior.com/noise); [出典](https://gradiently.design/guide/svg-noise-filter)。
- グレインを動かすなら filter の `seed` を毎フレーム変更せず、オーバーサイズのタイルを `transform` で数段階にずらす（`inset:-50%` で縁を覆う）[出典](https://gradiently.design/guide/css-noise-texture)。
- `transform` / `opacity` は合成スレッドで処理されレイアウトもペイントも発生しない。逆にジオメトリ変更は style→layout→paint を走らせる。`will-change` は問題が発生した場合のみ、必要な間だけ付与する [出典](https://developer.mozilla.org/en-US/docs/Web/Performance/Guides/Animation_performance_and_frame_rate); [出典](https://www.browser-rendering.com/compositing-and-gpu-acceleration/transform-and-opacity-best-practices/)。
- ブレンド層を重ねすぎない（2 つのインク層 + グレインで 3 合成）。ヒーローやポスター領域に限定し、ページ全体には適用しない [出典](https://codefronts.com/design-styles/css-grain-texture/risograph-print-misregistration-texture/)。
- 高彩度インクを `oklch()` で定義する場合は sRGB フォールバックの HEX を先に宣言し、両ディスプレイで確認する [出典](https://freeframe.dev/blog/designing-overprint-a-risograph-portfolio)。

### 4.4 セマンティクス

- テクスチャは疑似要素または空要素 + `aria-hidden="true"`。見出しの版ズレ複製は `content: attr(...) / ""` でスクリーンリーダーの二重読みを防ぐ [出典](https://freeframe.dev/blog/designing-overprint-a-risograph-portfolio)。
- 文字を画像に焼き込まない（1.4.5 Images of Text）。手書き風 (#14) も **DOM 上の実テキスト**として実装し、ズーム・リフロー・読み上げを可能にする [出典](https://accessibility.build/guides/text-over-images)。
- 装飾が情報を持つ場合（例: 色だけで状態を表す）はテキスト/アイコンで代替し、色のみに依賴させない。

### 4.5 調査上のギャップ

- 公式のカラースクリプト数値（HEX/CMYK）は公開されておらず、上記 HEX はすべて UI 提案値である。正確な色を必要とする場合は各 MV の公式アートブック／クレジット類を別途確認する必要がある。
- 『千鳥』『櫂』の車窓・赤い衣装・色彩遷移の詳細は二次（ファン考察）に依存する。一次の制作インタビューでは『火星人』のロトスコープと多言語タイポグラフィ、全編を通したカラー設計の統一は確認できるが、『千鳥』の色彩設計そのものは確認できていない。
- テープ・カセット・古いラベルというモチーフは、MV の一次資料ではなく「書簡型小説の物質性」とリポジトリ既存コンポーネントからの**推論**である。MV 直接の根拠は見つかっていない。
